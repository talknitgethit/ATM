# 🏧 ATM Project

A simple command-line ATM simulation built with Python.

## Features

-  Deposit money
-  Withdraw money
-  Check account balance
-  View transaction history
-  Built using Python classes

---

##  Getting Started

### Requirements

- Python 3 installed

### Run the Program

```bash
python atm.py
```

---

## Menu

```text
Welcome to the ATM!

1. Deposit
2. Withdraw
3. Check Balance
4. Transaction History
5. Exit
```

- Python 3
- Object-Oriented Programming (OOP)
